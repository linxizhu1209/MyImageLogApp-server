MyImageLog

사진과 함께 기록하는 나만의 일상 로그

APK 다운로드

Android 7.0(API 24) 이상 지원

화면 미리보기

홈 화면 스크린샷 준비 중
업로드 화면 스크린샷 준비 중
상세 화면 스크린샷 준비 중

주요 기능

  • 사진 업로드 + 메모

    찍은 사진과 함께 그날의 메모를 한 번에 저장하세요.

  • 주간 / 일별 타임라인

    날짜별로 정리되는 타임라인에서 추억을 쉽게 되돌아볼 수 있어요.

  • 구글 / 카카오 로그인

    별도 회원가입 없이 OAuth로 빠르게 시작할 수 있습니다.

  • 서버 동기화

    기기를 바꿔도 안전하게 데이터가 보존됩니다.

설치 가이드

  1. 위의 APK 다운로드 버튼을 눌러 파일을 받습니다.
  2. 안드로이드 설정 → 보안 → 출처를 알 수 없는 앱 설치 허용을 켜주세요. (기종에 따라 "알 수 없는 앱 설치", "이 출처 허용" 등으로 표시될 수 있습니다.)
  3. 다운로드된 APK 파일을 탭하여 설치를 진행합니다.
  4. 설치가 완료되면 앱을 실행하고 로그인하여 사용하세요.
